# Birthday Celebration 🎉

This is a fun and animated birthday celebration website template ready to deploy!

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

Click the button below to deploy instantly:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/birthday-celebration)

Or use Vercel CLI:
```bash
npm install -g vercel
vercel
```

## Features

- 🎂 Animated birthday cake
- 🎊 Confetti effects
- 🦄 Cute floating characters
- 💕 Pink theme with gradients
- ✨ Smooth animations
- 📱 Fully responsive
- 🚀 Optimized for Vercel

## Customize

Edit [app/page.tsx](app/page.tsx) to:
- Change the birthday date (May 22)
- Modify the greeting message
- Update colors and styling
